## 📌 Project Overview

PhytoScan AI is an end-to-end artificial intelligence system
that identifies **30 medicinal plant species** from photographs
and provides complete pharmacological information including
chemical composition, toxicity classification, dosage guidance,
and herb combination safety analysis.

> **The global antimicrobial resistance (AMR) crisis kills
> 1.27 million people annually (WHO, 2022). PhytoScan AI
> helps communities safely use natural plant medicine as
> an evidence-based alternative.**

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🔍 **Plant Recognition** | Upload photo → AI identifies species with 90.4% accuracy |
| ⚗️ **Chemical Composition** | Active compounds — alkaloids, flavonoids, terpenes |
| ☠️ **Toxicity Classification** | 4-tier safety system — Safe / Mild / Moderate / Highly Toxic |
| 💊 **Dosage Guide** | Correct amount and preparation method per plant |
| 🧬 **Herb Combination Engine** | Synergistic / Dangerous combination detection |
| 📊 **Statistical Analysis** | t-test, chi-square, regression, confusion matrix |
| 🌐 **Web Application** | Live Streamlit app — no installation needed |

## 📊 Statistical Results

| Statistical Test | Result | Conclusion |
|-----------------|--------|------------|
| One-Sample t-Test | t=1.764 > 1.699 | Accuracy significantly > 85% ✅ |
| Chi-Square Test | χ²=22.4 > 5.991 | Non-uniform distribution ✅ |
| Pearson Correlation | r = +0.94 | Strong epoch-accuracy link ✅ |
| Linear Regression | R² = 0.883 | 88.3% variance explained ✅ |
| F-Statistic | F = 35.04, p<0.001 | Model significant ✅ |

## 🧪 Knowledge Base — Information Per Plant
